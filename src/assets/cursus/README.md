# Cursus product screens

Captured on 19 October 2026 from the local Cursus UI source at commit `ccfe3d6aaef2b8d2903ddc8cce8690c9ff661335`.

The screenshot harness renders the real `AppShell`, `Board`, `CollectionTable`, `ChatPanel`, and `QuizView` components with Cursus's stylesheet. Next.js navigation and server-action adapters are stubbed locally; no authentication, Supabase, OpenAI, or other application backend is used. The composition supplies a collection/material heading and explicitly labels the screens as sample study data.

All task names, dates, account details, chat messages, and quiz content are demonstration fixtures. The sample answer text is supplied for the UI capture rather than generated by a live model. The screens demonstrate the interface, not a live-account session or a measured model result.

- `board.png`: a collection board with status, priority, and due-date fields.
- `table.png`: the same sample collection in the table view.
- `chat.png`: the actual chat panel with example messages and a source reference.
- `quiz.png`: the actual quiz view with a selected answer and explanation.

Images are 1440×900 PNGs. The portfolio gallery provides descriptive alt text, native modal focus handling, Escape-to-close, previous/next controls, and arrow-key navigation.
