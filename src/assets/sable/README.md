# sable screens

Captured on 2 November 2026 from a local Release build of sable (compiled 28 October, after notes, markup, spreads and presentation mode landed), using a short sample document written for the screenshots. The highlight, underline and note were added in sable itself.

- `reader.png`: Default night preset with page thumbnails
- `notes.png`: Sepia preset with a highlight, an underline and a note, and the comments panel open
- `find.png`: Find with highlighted matches
- `spread.png`: odd-page spreads in the Redeye preset

Each image is 1440 × 774.
